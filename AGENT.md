# Hero Section Vault — 100 Designs Challenge

## Project Purpose
Personal design challenge creating 100 hero sections across various industries to improve visual composition, typography hierarchy, and first-impression design skills. Created by Marcos Martin Dominguez.

## Tech Stack
- **No code** — Design asset repository
- **Format**: PNG files (hero section mockups)
- **Tools**: Design software (Figma/equivalent)

## Folder Structure
```
/20 - Home           # Home category designs
/20 - Layouts       # Layout variation examples
/20 - Mobile + Layout # Mobile-responsive layouts
/20 - Web           # Web-specific designs
/automocion         # Automotive brands
/dashboards-interfaces # Admin dashboards, functional UIs
/deporte            # Sports teams, fitness
/ecommerce          # Product-focused, conversion
/entretenimiento-media # Entertainment, media, events
/experimental-creativo # Experimental concepts
/gastronomia        # Restaurants, food
/marcas-premium     # Premium branding, luxury
/software-digital  # SaaS, tech platforms
/viajes-naturaleza # Travel, tourism, nature
```

## Key Components
- **100 hero section PNG mockups** numbered chronologically (1-100)
- Each file: `{DESIGN_NAME} - {NUMBER}.png`
- Category breakdown:
  - Software & Digital
  - Marcas Premium
  - E-commerce
  - Automoción
  - Dashboards & Interfaces
  - Entretenimiento & Media
  - Deporte
  - Viajes & Naturaleza
  - Gastronomía
  - Experimental & Creativo

## Important Patterns
- Number in filename = chronological creation order
- Focus areas: message clarity, typography hierarchy, whitespace, visual contrast
- Each design optimized for first-impression impact

## How to Run
**Not a code project.** This is a design asset repository. To view:
- Open PNG files in any image viewer/browser
- Or import into Figma/design tool for editing
